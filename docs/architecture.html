2. 对话状态机 (Dialogue State Machine)

stateDiagram-v2 [*] --> START : 用户打开页面 START --> COLLECTING : 发送欢迎语 COLLECTING --> MATCHING : 特征足够 COLLECTING --> COLLECTING : 追问补充 MATCHING --> PRESENTING : 匹配成功 MATCHING --> COLLECTING : 无结果,放宽条件 PRESENTING --> MATCHING : 用户修改/追加条件 (refine) PRESENTING --> FEEDBACK : 用户点击满意/不满意 FEEDBACK --> MATCHING : 继续调整 FEEDBACK --> END : 用户满意结束 PRESENTING --> END : farewell COLLECTING --> END : farewell note right of MATCHING 执行流程: 1. encode_query → 特征向量+掩码 2. compute_similarity → 余弦+欧氏 3. hard_filter → 硬约束过滤 4. filter_candidates → 阈值筛选 5. rank_and_explain → 排序+解释 end note note right of PRESENTING 关键规则: 用户在此状态提交任何新特征 → 强制走 refine→match 流程 → 累积之前条件,不重置 end note

硬约束过滤matcher.py学历/血型精确匹配，身高范围匹配，体型/肤色精确匹配；不满足则直接排除
阈值筛选matcher.py综合得分 ≥ 0.7 方可入选
排序解释ranker.py取 Top-5，为每位候选人生成自然语言匹配理由

6. 项目文件结构

文件模块职责
main.py入口FastAPI 应用创建、启动加载数据/模型、注册路由、静态文件服务
config.py / .env配置LLM API Key/URL/Model、数据路径、匹配参数、服务端口
api/
api/chat.pyAPIPOST /api/chat — 普通对话接口，含 mock NLU 回退
api/chat_stream.pyAPIPOST /api/chat/stream — SSE 流式对话接口
api/feedback.pyAPIPOST /api/feedback — 用户反馈接口
dialogue/
dialogue/nlu.py对话LLM 意图识别 & 特征提取，System Prompt 定义
dialogue/dialogue_flow.py对话对话状态机：START→COLLECTING→MATCHING→PRESENTING→FEEDBACK→END
dialogue/response_gen.py对话综合 NLU 结果、对话状态、匹配结果生成最终回复
dialogue/session.py对话会话上下文管理：状态、特征累积、历史记录、超时清理
core/
core/data_loader.py核心从 Excel 加载捐精人数据，清洗列名，过滤可用记录
core/feature_engine.py核心特征编码器：序数/归一化/One-Hot 编码，生成 26 维特征矩阵
core/matcher.py核心相似度计算(余弦+欧氏加权)、硬约束过滤、候选人筛选
core/ranker.py核心Top-K 排序，为每位候选人生成自然语言匹配解释
frontend/ & voice/
frontend/index.html前端对话界面 (TailwindCSS)、SSE 流式渲染、候选人卡片、语音交互
voice/asr.py语音ASR 占位模块（原型使用前端 Web Speech API）
voice/tts.py语音TTS 占位模块（原型使用前端 SpeechSynthesis）
