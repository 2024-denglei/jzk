Figure 1. Research-style architecture diagram of the LLM-assisted donor matching dialogue system. The system separates semantic interpretation from deterministic matching: the LLM converts natural language into structured features and constraint levels, while the matching core performs feature encoding, dynamic hard-constraint filtering, masked similarity computation, and explainable ranking.
