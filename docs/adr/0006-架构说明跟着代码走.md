# 架构说明跟着代码走，不对外提供手画图

`docs/` 下曾有多份手画 SVG/HTML，并经 `GET /architecture` 对外提供。那些图描述的是已经零引用的模块，漂移没有报错也没有堆栈。我们决定当前结构只写在仓库里的 Markdown（`docs/architecture.md`），历史 plan / spec 放进 `docs/archive/`，不再用 HTTP 端点发布架构图。

## 为什么

重画 SVG 只是把漂移的起点重置一次。手画图与代码没有机械核对，下一次改名后它会再静默过期。Markdown 仍然会过期，但它和代码在同一个 review 里改，而且守卫测试会检查它是否还叫得出当前的包名。

## 代价

没有一张可投影的总图。需要看分层时读 `docs/architecture.md` 和 `tests/test_layering.py`。
