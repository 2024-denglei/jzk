# 替换捐精人模拟数据并同步详情页

## 背景

用《新生成的模拟捐精人信息数据3000条(1).xlsx》替换旧人造数据；运行时仍以 PostgreSQL `donor.donors` 为准，Excel 仅作导入源。

## 决策

- 导入前清空旧捐精人，再写入 3000 条
- 详情页去掉检测摘要、标本情况（新表无这些列）
- 详情页按新表完整展示；列表卡片与筛选不变

## 范围

- 更新默认 `DATA_FILE_PATH`
- 导入支持 `--replace` 清库
- 前端 `DonorInfo` + `DonorDetailPanel` 对齐新字段

## 非范围

- 不扩展筛选 / NLU / 匹配特征
- 不改列表卡片摘要字段
